# huohuo

用 GitHub 和 Grok Bot 一起工作时的索引：记下我们在用的仓库，以及每次相关改动。

English: An index of the GitHub repositories we work on, and a changelog of GitHub-related work done with Grok Bot.

## 用途

- 仓库清单：见下方表格。完整目录在 [repos.md](repos.md)，以后往那里追加。
- 改动记录：写在 [CHANGELOG.md](CHANGELOG.md)。新建仓库、把仓库加进索引，以及其他和 GitHub 相关的工作，各记一条。

## 怎么更新

1. 新增仓库：在 [repos.md](repos.md) 表尾加一行，并在本页表格里补上同一条链接。
2. 记一笔改动：在 [CHANGELOG.md](CHANGELOG.md) 最上方追加日期（`YYYY-MM-DD`，时区 Asia/Shanghai）和几条要点。
3. 提交到分支并开 Pull Request。
